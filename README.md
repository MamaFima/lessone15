# Репозиторий с примерами работы с массивами, парсерами и визуализацией данных

Данный репозиторий содержит проекты, демонстрирующие навыки работы с массивами, парсингом данных из веб-страниц и их последующей визуализацией. Основной упор сделан на использование библиотек Python для автоматизации и анализа данных.

## Основные возможности
1. **Работа с массивами и обработка данных**:
   - Обработка массивов с использованием библиотеки `pandas`.
   - Расчёт статистических показателей, таких как среднее значение, медиана и распределение.

2. **Парсинг данных с веб-страниц**:
   - Использование библиотеки `selenium` для автоматизированного сбора данных.
   - Примеры парсинга цен с коммерческих веб-ресурсов.
   - Реализация бесконечной прокрутки для загрузки скрытых элементов на странице.

3. **Визуализация результатов**:
   - Построение гистограмм и графиков с использованием библиотеки `matplotlib`.
   - Примеры представления распределения цен на товары.

## Пример работы
### Парсинг цен на диваны
Один из представленных проектов осуществляет сбор данных о ценах на диваны с сайта. Основные этапы работы:
1. **Сбор данных**:
   - Автоматический скроллинг страницы для загрузки всех элементов.
   - Извлечение цен с помощью парсинга HTML-тегов.
   - Сохранение собранных данных в CSV-файл.

2. **Анализ данных**:
   - Расчёт средней цены на основе собранной информации.
   - Вывод результатов в консоль.

3. **Визуализация**:
   - Построение гистограммы распределения цен.
   - Визуализация данных с разбивкой на интервалы.

Пример кода:
```python
# Вычисление средней цены
mean_price = df['Price'].mean()
print(f"Средняя цена на диваны: {mean_price} руб.")

# Построение гистограммы
plt.hist(df['Price'], bins=30, edgecolor='black')
plt.title('Гистограмма цен на диваны')
plt.xlabel('Цена (руб.)')
plt.ylabel('Частота')
plt.grid(True)
plt.show()
```

## Используемые технологии
- **Python 3.x**: основной язык разработки.
- **Selenium**: библиотека для автоматизации взаимодействия с веб-страницами.
- **Pandas**: обработка данных и работа с CSV-файлами.
- **Matplotlib**: построение графиков и визуализация.

## Примечания
- Скрипты требуют установленного браузера Google Chrome и совместимого драйвера ChromeDriver.
- Для работы в фоновом режиме добавлен параметр `--headless`.
- Используйте виртуальное окружение для установки зависимостей.
